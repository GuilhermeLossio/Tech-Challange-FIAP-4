Serving Rules
Operational constraints enforced by the product.
  • Standard users can only inspect and filter data.
  • No training artifact can be edited from this interface.
  • No raw, processed, or model file can be uploaded or replaced here.
  • Quantum inference is served only from batch materialized data.
  • Live requests always use the classical local model.
Prediction Methods
The client view exposes both serving paths, but only one can run live.
Classical next-day prediction
online

Uses the trained Keras LSTM model and a 60-day closing-price window to estimate the next trading session close.

  • Served live.
  • Depends on locally available Keras artifacts and scaler metadata.
Quantum future forecast
batch only

Serves precomputed quantum rows from the materialized future_predict dataset without triggering IBM Quantum token usage.

  • Never executed online by the client view.
  • Some rows may expose a price proxy instead of a direct regressed close.
