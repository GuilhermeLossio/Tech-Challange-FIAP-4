Technical explanation

The VQC is approximately 2.8x slower than the LSTM per step. Over 30 steps, the total runtime difference is approximately 2.60s. This is expected because each VQC step may involve running a variational quantum circuit, sampler execution, transpilation, and bitstring interpretation, while the LSTM mainly performs optimized matrix operations.

The VQC is approximately a direction and volatility model in this interface. Its output is converted into an estimated price path through the configured proxy, so it should not be read as a direct price regression.

Serving Rules
Operational constraints enforced by the product.
  • Standard users can only inspect and filter data.
  • No training artifact can be edited from this interface.
  • No raw, processed, or model file can be uploaded or replaced here.
  • Quantum inference is displayed only from batch materialized data.
  • The static page does not execute local models or runtime requests.
Prediction Methods
The client view displays precomputed classical and quantum outputs.

  • No browser-side execution is required.
  • Some rows may expose a price proxy instead of a direct regressed close.
